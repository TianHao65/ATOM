# DeepSeek-V4.1-Flash-1017 TP4 release evidence

## What

The November 19 delivery notes cover DeepSeek-V4.1-Flash-1017 and its offline FP4PTPC checkpoint through ATOM and SGLang, with BF16 KV cache and optional DSpark.

## Data

| Component | Recorded revision |
|---|---|
| SGLang | 0.5.22, [`baa9befa`](https://github.com/sgl-project/sglang/commit/baa9befa381511cd4d56f83980951e5a45fffc6d) |
| AITER | 0.1.30.dev222, [`58b5015d`](https://github.com/ROCm/aiter/commit/58b5015d46ae04e72284f2a5113523b312f8aff3) |
| ATOM | 0.1.11.dev5, local branch `feat/dsv41-pr3518-port`, `988052da` as recorded in the release notes |

The tested checkpoint names are `deepseek-ai/DeepSeek-V4.1-Flash-1017` and `ginsongsong/DeepSeek-V4.1-Flash-1017-FP4PTPC`. The notes describe cache-off serving and a random benchmark of 100,000 input and 1,500 output tokens at TP4. The native checkpoint had an optional `*.ffn.experts*: ptpc_fp8` online recipe in the documented launcher instructions.
